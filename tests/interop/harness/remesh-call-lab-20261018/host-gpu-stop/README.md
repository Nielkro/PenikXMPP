Failures record only a fixed phase, return code and traceback leaf basename/line/function, never exception text, raw stderr, arguments or private configuration.

`stop_ack.py` binds each pending and settled record to the exact role, batch, freeze, process identities, request UUID and creator process. Complete private JSON is atomically linked into a once-only name after flush/fsync; readers never see the writer's partial JSON. The fixed deadline is the earlier of original control entry + 55 seconds and the existing batch expiry. Polling, instrumentation exit and settlement never renew it. A dead reader reaches that same bounded timeout. Only normal instrumentation completion enters the drain, before the original cleanup changes state or kills the emulator. Expiry or absent intent proceeds to cleanup. SystemExit/KeyboardInterrupt during the drain first completes the original owned cleanup and then propagates the original abort. No mutation is retried and no deadline or state guard is loosened.
